Find by scan, banner or service

Paste an nmap -sC -sV result, a service banner, or just port numbers / names (e.g. 445 ldap kerberos). It finds the ports, pulls the target IP, and shows the commands for each. Anything not covered yet, you can add in one click.

Extend & deploy

Every card is one object in the DATA array near the top of the script. Add your own from a lab write-up by copying the shape — ports is what makes it show up in By-Port and Scan mode:

{ phase:"lateral", cat:"Active Directory", tags:["ad"], ports:[445],
  title:"Dump LSA secrets",
  cmd:"impacket-secretsdump {{DOMAIN}}/{{USER}}:{{PASS}}@{{IP}}",
  note:"Pull hashes once you have admin on the host.",
  src:{t:"Impacket", u:"https://github.com/fortra/impacket"} }

Any {{TOKEN}} in a cmd becomes a target field automatically; list new ones in VARS. New service? Add its number to SERVICES and tag entries with that port.

Deploy: one self-contained file, no build step and no backend. Put index.html in a repo with GitHub Pages on, or drag the folder onto Vercel / Netlify.
